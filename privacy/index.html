2. Overview

The calculator runs entirely in your browser. There are no accounts, no cookies, no local storage, no analytics, no tracking and no ads. The website does not load any external fonts, scripts or other third-party resources.

3. Hosting on GitHub Pages

This website is hosted on GitHub Pages, a service of GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA.

When you open the website, your browser sends technical data to GitHub's servers. This includes your IP address, the requested address (including the settings described in section 5), date and time of the request, browser type and the referring page. GitHub processes this data to deliver the website and keep it secure, and may store it in server logs.

Legal basis is Art. 6 (1) (f) GDPR: the legitimate interest in providing a secure and reliable website. GitHub may process data in the USA. Details, including the safeguards GitHub uses for international transfers, are in the GitHub General Privacy Statement.

4. Screen detection

To pre-select your current monitor, the website reads your screen resolution and display scaling in your browser. This happens only on your device. The website does not store these values or send them anywhere.

5. Settings in the address

Your selected aspect ratios are written into the page address (for example ?monitor=16:9&ratio=4:3) so you can share your setup. This happens locally in your browser. If a monitor was detected as a custom resolution, it can appear there as well (for example 3440x1440).

When you reload the page or open such a link, the full address including these settings is sent to GitHub as part of the request described in section 3.

6. Links to GitHub

Links to the source code take you to github.com. GitHub's own privacy statement applies there.
